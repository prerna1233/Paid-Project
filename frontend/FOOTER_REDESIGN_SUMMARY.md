## 🎨 CSS Highlights

### **Advanced Styling:**

```css
/* Animated Link Arrows */
.footer-links a::before {
  content: '▸';
  position: absolute;
  transition: left 0.3s ease;
}

/* Social Media Ripple Effect */
.social-link::before {
  content: '';
  background: rgba(255, 255, 255, 0.2);
  border-radius: 50%;
  transition: width 0.4s, height 0.4s;
}

/* Dual-Color Title Underline */
.column-title::after {
  content: '';
  width: 50px;
  height: 3px;
  background: var(--gov-accent);
}

/* Hover Effects */
.contact-item:hover {
  transform: translateX(5px);
}

.social-link:hover {
  transform: translateY(-5px);
  box-shadow: 0 5px 15px rgba(58, 95, 74, 0.3);
}
```
